# Improvement Deep-Dive — nostr-skills-registry — 2026-10-21

## Top recommendations (ranked, with effort S/M/L)
1. **Fix or archive — register.js is broken as written**: (a) `import { NDK } from '@nostr-dev-kit/ndk'` — NDK is a **default** export, the named import is `undefined` and `new NDK()` throws; (b) no signer is ever configured, so `ev.publish()` rejects; (c) no `package.json`, so even a fixed import has no pinned dependency. Either ship the 3-line fix + manifest or archive the repo as a sketch. [S]
2. **If kept: add package.json** (`@nostr-dev-kit/ndk` pinned, e.g. `^2.x`, lockfile, `"type": "module"`, node >= 18) and a signer (`NDKPrivateKeySigner` from env, never CLI arg — argv is world-readable via `ps`). [S]
3. **EOSE-based discovery**: `discover()` waits a fixed `setTimeout(4000)` — silent data loss on slow relays. Wait for EOSE per relay (or `ndk.fetchEvents` which does this). [S]
